# FocusFlow · 个人专注与任务管理工具

FocusFlow v1.2.0 提供任务管理、专注计时、刷新恢复、进度累计、专注统计，以及 JSON 备份与恢复。默认中文，右上角可切换英文，语言选择随设置保存在当前浏览器。
